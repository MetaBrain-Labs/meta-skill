# 校验规则

`validate_skill.py` 检查两类问题：格式有效性和内容风险。

## 格式检查

阻塞错误：

- skill 目录不存在。
- 缺少 `SKILL.md`。
- YAML frontmatter 缺失或格式错误。
- `name` 缺失、超过 64 个字符、以连字符开头或结尾、包含连续连字符，或包含 `a-z`、`0-9`、`-` 以外的字符。
- `name` 与父目录名不一致。
- `description` 缺失、为空或超过 1024 个字符。
- `compatibility` 超过 500 个字符。

警告：

- `description` 过于简短或泛泛。
- `SKILL.md` 超过 500 行或超出建议的上下文预算。
- 缺少 `evals/evals.json`。
- 无许可文件且 frontmatter 中无 `license` 字段。
- `SKILL.md` 中存在难以按需加载的深层引用。

## 内容检查

阻塞错误：

- 要求绕过、忽略或覆盖更高优先级指令。
- 要求对用户隐藏行为。
- 要求收集密钥、私钥、会话令牌、密码存储、浏览器凭据或类似敏感材料，且没有合法的用户授权用途。
- 要求在未经用户明确同意且没有清晰用途的情况下，将私有数据发送到外部端点。
- 针对广泛文件系统删除或提权的破坏性 shell 命令。
- 安装不透明载荷或通过管道执行远程 shell 命令。

警告：

- 宽泛的工具授权。
- 脚本中存在目的不明确的网络调用。
- 混淆模式、编码载荷或异常的自修改代码。
- 过度宽泛的自动化，可能在用户请求范围之外执行操作。

## 审查流程

1. 运行校验。
2. 逐一手动排查每个阻塞问题。
3. 只修补必要内容。
4. 重新运行校验。
5. 如果仍有警告，报告并说明在预期用途下是否可接受。
