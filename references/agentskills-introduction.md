# 什么是Agent Skills

## 概览
Agent Skills（智能体技能）是一种通过将专业知识、工作流规范固化为可复用资产从而为 AI Agent 赋予新的能力和专业知识的标准规范。
Agent Skills 的本质不是工具，而是：
```
行为规范 + 专业知识 + 使用时机的组合
```

## Agent Skills的结构
Agent Skills 是一种轻量级、开放的标准规范，用于将专业知识和工作流程扩展为 AI Agent 的能力。在项目结构上，一个 skill 是一个至少包含 SKILL.md 文件的文件夹。SKILL.md至少应包含元数据（name 和 description）以及 Agent 如何执行特定任务的说明。Skills 还可以打包脚本、参考资料、模板及其他资源。
```
my-skill/
├── SKILL.md          # 必需：元数据 + 说明
├── scripts/          # 可选：可执行代码
├── references/       # 可选：文档
├── assets/           # 可选：模板、资源
└── ...               # 其他文件或目录
```

## 为什么使用Agent Skills
AI Agent 的能力越来越强，但在实际工作中常缺乏完成任务所需的有效上下文或指导。Skills 通过把专业知识以及特定上下文，打包为可移植、可版本控制的文件夹来解决这个问题；Agent 会按需加载这些文件夹。这为 Agent 提供了：

- 领域专业知识：将专业知识捕捉为可复用的说明和资源，例如法律审查流程、数据分析流水线、演示文稿格式规范等。

- 可重复的工作流程：将多步骤任务转化为一致、可审计的流程。

- 跨产品复用：只需构建一次 skill，就可以在任何兼容 skills 的 Agent 中使用。

## 核心形式
- 一个 skill 就是一个文件夹，里面必须有一个 SKILL.md 文件（包含说明和元数据），可选其他资源文件（如脚本、示例、参考文档）。
- skill 核心文件为 SKILL.md，该文件将 某类事情应该怎么专业做 这件事，封装成一个可复用、可自动触发的能力模块
- 本质相当于向 Agent 发放一本专业手册/操作手册，AI 不会每次都从零学习，而是根据任务自动调用手册中的知识。
