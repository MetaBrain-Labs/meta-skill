# 候选 skill 排序

## 排序维度

按以下维度对候选 skill 进行综合评分，优先级从高到低：

1. **相关性**：skill 描述与用户需求的匹配程度；触发场景是否精确覆盖用户任务。
2. **来源可信度**：官方或已知维护者的仓库 > curated 清单 > 社区索引 > 未知来源。
3. **校验状态**：无阻塞错误且警告少的候选优先；有阻塞错误的候选不推荐。
4. **范围收敛度**：聚焦、边界清晰的 skill 优先于功能堆叠的大而全 skill。
5. **许可清晰度**：有明确 OSI 兼容许可证的候选优先；无许可证或许可不明确的候选降级。
6. **维护信号**：近期有提交、issue 响应或版本发布的仓库优先；长期无维护的仓库降级。
7. **权限需求**：只申请完成任务所需最小权限的 skill 优先；权限过宽的候选降级并说明原因。

## 使用 `scripts/rank_candidates.py`

```bash
python scripts/rank_candidates.py candidates.json --query "用户查询" --out ranked.json
```

脚本基于上述维度对 `candidates.json` 中的候选进行打分和排序，输出 `ranked.json`。

## 人工复核

脚本排序后，应人工复核前 3 名候选的 `SKILL.md` 内容，确认：

- 描述与实际主体一致，没有隐藏行为。
- 脚本用途合理，网络端点已说明。
- 许可证允许预期的使用方式。
